📌 About The Project

Matrix Infinity Flow is a lightweight browser-based animation that recreates the iconic Matrix digital rain using HTML Canvas, combined with a neon green glitch text overlay for a cyberpunk hacker aesthetic.

Designed to be:

⚡ Lightweight

🧪 Visually engaging

🛠 Easy to customize

🎯 Beginner friendly

🚀 Live Features

🖥 Fullscreen Canvas Rendering
🔢 Dynamic Binary Rain Generation
⚡ Smooth Frame Animation
🧪 CSS Glitch Distortion Text
💚 Neon Cyberpunk Color Theme
📦 Zero Dependencies

Change Hacker Text

  content: "YOUR TEXT";
}

Change Rain Color

Change Animation Speed
setInterval(rain, 20);
