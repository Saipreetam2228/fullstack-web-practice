# Online Student Admission Form – Project README

This project demonstrates a complete **Online Student Admission Form** using **HTML, CSS, and JavaScript**.  
It is designed for **academic, lab, and learning purposes**, showing how front-end technologies work together to create a structured and interactive web page.

---

## 📁 Project Files

- `index.html` – Defines the structure and content of the web page  
- `task2.css` – Handles styling and layout  
- `task2.js` – Adds basic interactivity and client-side behavior  

---

## 1️⃣ HTML File – `index.html`

### Purpose
The HTML file provides the **basic structure** of the Student Admission Form and contains all form elements.

### Key Features

#### 📄 Document Structure
- Uses `<!DOCTYPE html>` to declare HTML5.
- `<html lang="en">` sets the document language.
- `<head>` contains:
  - Character encoding (UTF-8)
  - Page title
  - Link to external CSS file

#### 🧱 Page Layout
- `<h1>` displays the main title of the form.
- `<p>` gives a short description to users.
- `<hr>` separates sections visually.
- `<form>` groups all admission-related inputs.

#### 📝 Form Sections
- **Personal Information**
- **Contact Details**
- **Academic Information**

#### 🧩 Form Elements Used
- Text, number, date, email, and telephone inputs
- Radio buttons for gender selection
- Checkboxes for skills selection
- Dropdown (`<select>`) for course choice
- `<textarea>` for descriptive input
- File upload input for photograph
- Declaration checkbox
- Submit and Reset buttons

#### 📌 Footer
- Displays copyright information
- Shows designer name
- Links the external JavaScript file at the end of the body

---

## 2️⃣ CSS File – `task2.css`

### Purpose
The CSS file is used to **style the admission form**, making it clean, professional, and user-friendly.

### Styling Features

#### 🎨 General Styling
- Uses a clean font (Arial, Helvetica)
- Applies a soft gradient background
- Adds spacing and readable text colors

#### 🏷 Headings & Text
- Centers the main heading
- Uses borders and colors for section headings
- Styles paragraph text uniformly

#### 🧾 Form Layout
- Card-style design with:
  - White background
  - Rounded corners
  - Box shadow
- Centers the form and ensures responsiveness

#### ✏️ Input Styling
- Uniform styling for all inputs, dropdowns, and textareas
- Focus effects for better user experience
- Vertical resizing enabled for textarea

#### 🔘 Buttons
- Submit and Reset buttons styled differently
- Hover effects added for interactivity

---

## 3️⃣ JavaScript File – `task2.js`

### Purpose
The JavaScript file adds **basic client-side functionality** to the form.

### Functionality
- Handles form-related interactions
- Can be used for:
  - Input validation
  - Handling submit events
  - Showing alerts or messages
- Enhances user experience without page reloads
